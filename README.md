# 🎓 Campus Event Q&A Assistant (GenAI Project)

A GenAI-powered assistant that answers student queries about campus events using the Gemini API.

---

## 🚀 Features

- 🔍 Answers questions about campus events
- 📦 Returns structured JSON responses for event queries
- 💬 Handles off-topic queries with conversational responses
- ⚡ Powered by Google Gemini API
- 🔐 Secure API key handling via environment variables

---

## 🧠 How It Works

1. User asks a question
2. System prompt provides event database context
3. Gemini model processes query
4. Returns:
   - JSON (for event queries)
   - Plain text (for non-event queries)
